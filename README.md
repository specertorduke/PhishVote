# PhishVote

A comprehensive phishing detection and analysis project that combines machine learning, data analysis, and interactive visualization to identify and classify phishing attempts.

## Project Overview

PhishVote is designed to tackle phishing attacks through data-driven analysis and machine learning techniques. The project leverages Jupyter notebooks for exploratory data analysis, experimentation, and model development, complemented by JavaScript and HTML for interactive visualizations and web-based interfaces.

## Repository Structure

- **Jupyter Notebooks (91.4%)**: Core data analysis, model training, and experimentation
- **JavaScript (5.2%)**: Interactive frontend components and visualizations
- **HTML (2.2%)**: Web interface templates
- **Python (1.2%)**: Supporting utilities and scripts

## Key Features

- 📊 Data analysis and exploration using Jupyter notebooks
- 🤖 Machine learning models for phishing detection
- 🎨 Interactive visualizations and dashboards
- 📈 Performance metrics and evaluation
- 🔍 Classification and analysis of phishing indicators

## Getting Started

### Prerequisites

- Python 3.7+
- Jupyter Notebook or JupyterLab
- Required packages (see requirements section)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/specertorduke/PhishVote.git
cd PhishVote
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

## Usage

1. Start with the Jupyter notebooks to explore the data and models
2. Review the analysis and results
3. Access the interactive visualizations through the HTML interface

## Technologies Used

- **Python**: Data processing and machine learning
- **Jupyter Notebook**: Interactive analysis and model development
- **JavaScript**: Client-side interactivity
- **HTML**: Web interface structure
